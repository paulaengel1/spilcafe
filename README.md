# Spilcaféen – Sustainable Web

Dette projekt er udarbejdet som en del af Sustainable Web på 3. semester af multimediedesigneruddannelsen på Erhvervsakademi Aarhus.

Projektet bygger videre på en tidligere version af Spilcaféen og har fokus på at redesigne og optimere spiloversigten på baggrund af audit og tests fra Del 1.

## Fokusområder

Projektet arbejder med:

- Bæredygtigt webdesign
- Webtilgængelighed
- Responsivt design
- Performance
- Brugeroplevelse

## Centrale optimeringer

I den optimerede løsning er der blandt andet arbejdet med:

- WebP-optimerede og lokale spilbilleder
- Lazy loading
- Semantisk HTML
- Alt-tekster og formularlabels
- Tastaturnavigation og synlige focus states
- Forbedret farvekontrast
- Responsivt layout til desktop, tablet og mobil
- Sticky søgefelt
- Forbedret søgning og filtrering

## Resultater

Efter optimeringen blev løsningen testet igen:

- Lighthouse Performance: 89 → 100
- Lighthouse Accessibility: 81 → 100
- Ecograder: 40 → 94
- Website Carbon Calculator: F → C
- Billeddata: ca. 7,27 MB → ca. 2 MB
